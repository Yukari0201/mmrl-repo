新增
- 恢复提供 riscv64 ABI 支持
- 支持 Android 17 QPR 3
- 提升 KernelSU 最低管理器版本要求到 1.0.1
- 新增开发者模式与命令行工具 lspctl，支持管理模块及作用域等功能
- 新增禁用安全模式的选项
- 新增横移返回手势开关

改进
- 大幅优化调用链性能，钩子执行成本约 27x speedup
- 优化框架启动和模块运行性能，降低日志记录开销
- 优化安全模式判定，更准确地识别系统界面反复崩溃，减少误触发
- 优化页面切换动画与悬浮底栏交互，支持记忆侧边导航栏的展开状态
- 改善恢复备份时的文件选择兼容性
- 优化安装包压缩，更新多语言文案

修复
- 修复一系列 UI 问题
- 修复部分荣耀设备上的框架启动问题
- 修复部分模拟器及 32 位应用兼容环境中的运行和模块加载问题
- 修复部分场景下模块重复加载、模块信息更新不及时的问题
- 修复部分模块共存时的冲突，以及模块运行过程中可能出现的失效或崩溃
- 修复长日志处理异常和部分安装包解压兼容性问题
- 修复 XposedHelpers 字段写入时部分基本类型拓宽转换失败的问题，包括 char 转 int、long 转 float 等

Added
- Restored riscv64 ABI support
- Added support for Android 17 QPR 3
- Raised the minimum manager version requirement of KernelSU to 1.0.1
- Added developer mode and CLI tool lspctl, with support for managing modules, scopes, etc
- Added a toggle to disable safe mode
- Added a toggle for the swipe-back gesture

Improved
- Significantly optimize call chain performance, with 27x speedup on hook execution cost
- Optimized framework startup and module runtime performance, reducing logging overhead
- Optimized safe mode detection, more accurately identifying repeated System UI crashes and reducing false triggers
- Optimized page transition animations and floating bottom bar interactions, with support for remembering the expanded state of the side navigation bar
- Improved file selection compatibility when restoring backups
- Optimized package compression, updated multilingual copy

Fixed
- Fixed a series of UI issues
- Fixed framework startup issues on some Honor devices
- Fixed runtime and module loading issues in some emulators and 32-bit app compatibility environments
- Fixed issues with modules being loaded repeatedly and module information not being updated promptly in some scenarios
- Fixed conflicts when some modules coexist, as well as possible failures or crashes during module runtime
- Fixed issues with long log processing errors and compatibility when extracting some packages
- Fixed failures in widening conversions for some primitive types when writing fields with XposedHelpers, including char to int、long to float etc.
